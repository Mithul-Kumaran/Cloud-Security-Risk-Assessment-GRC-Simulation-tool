
# SecureCloud GRC Platform — Azure Risk Assessment

A sleek, enterprise-grade web application for performing cloud security risk assessments and GRC (Governance, Risk, and Compliance) simulations on Azure infrastructure. Built with a modern, minimalist design inspired by professional SaaS tools like ServiceNow and Microsoft Defender.

## What This Does

This interactive platform guides you through a comprehensive five-phase risk assessment workflow:

1. **Asset Inventory** — Catalog your Azure resources (VMs, databases, storage, networking)
2. **Risk Modeling** — Identify threats, vulnerabilities, and potential business impact
3. **Control Mapping** — Assign security controls to mitigate identified risks
4. **Compliance Framework Mapping** — Align controls with ISO 27001, SOC 2, and other frameworks
5. **Reporting** — Generate detailed findings, remediation steps, and compliance status

## Key Features

- **Risk Matrix Visualization** — Interactive 5x5 heatmap showing likelihood vs. impact
- **Dynamic Stat Cards** — Real-time dashboard metrics (critical/high/medium/low risks)
- **Control Management** — Assign, track, and toggle control implementations
- **Compliance Scoring** — See compliance posture across multiple frameworks at a glance
- **AI-Powered Chat** — Ask the platform questions about findings and remediation
- **Enterprise UI** — Clean, dark-mode sidebar navigation with breadcrumb tracking
- **Responsive Layout** — Works on desktop and tablet; optimized for professional workflows


## How to Use

1. Clone or download this repo
2. Open `index.html` in a modern browser (Chrome, Firefox, Safari, Edge)
3. Navigate through the five assessment phases using the sidebar menu
4. Fill in asset details, threats, controls, and compliance mappings
5. View the dashboard for risk scoring and status summaries
6. Chat with the AI assistant for guidance on remediation
